Flue feels mysterious for one reason: "harness" is overloaded across three layers, and nothing tells you they're different. Untangle the word and the whole framework snaps into focus.

Yes — Flue is a harness. More precisely, a framework for building agent harnesses: "Astro/Next.js, but for agents." It supplies the harness half of agent = model + harness; the model-calling loop itself lives one layer deeper, in pi-agent-core, which Flue wraps.

03 — WHAT YOU ACTUALLY WRITE

Agents vs Workflows

Two top-level authoring surfaces that look alike and mean different things. The clearest tell: runs belong to workflows only.

agents/<name>.ts · default-exports createAgent()

Agents

  • Addressable. Reached by URL: POST /agents/<name>/<id>
  • Persistent. The <id> is a durable instance — reuse it to continue.
  • Runtime builds the harness for you when a message arrives.
  • For conversations — support threads, chat, long-lived sessions.
workflows/<name>.ts · exports run()

Workflows

  • Bounded. Clear input → finished result. A job, not a chat.
  • Inspectable. Each invocation is a run with a runId (/runs, flue logs).
  • You call init(agent) to build the harness yourself.
  • For triggers — CI jobs, one-shot scripts, batches.
04 — THE SHOWPIECE

One prompt(), turn by turn

The layering, in motion. Hit Run to watch a single prompt() Operation drive the engine through its Turns — and see where Flue's loop ends and pi-agent-core's begins.

Operation = your call · Turn = one LLM round-trip
Insight 01

Structured output is forced tool-calling, not JSON mode. A result: schema becomes the parameters of a synthetic finish tool, plus a retry loop that nudges the model until it calls it.

Insight 02

Flue's loop ≠ the agent loop. runModelTurnWithRecovery is a thin recovery/persistence wrapper; the real read-act-observe cycle is pi-agent-core's. This trace is the layer-1 / layer-2 boundary, shown in motion.

The takeaway

Flue is to an agent harness what Next.js is to a web server — it never reinvents the loop, it builds everything around it.
